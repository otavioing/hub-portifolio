Calculadoras de Saúde

Índice de Massa Corporal(IMC)

Calcule a relação entre seu peso e altura para entender sua categoria de peso atual.

Taxa Metabólica Basal(TMB)

Descubra o mínimo de calorias que seu corpo queima em repouso total por dia.

Percentual de Gordura

Uma estimativa detalhada da sua composição corporal baseada em medidas antropométricas.

Sobre o HealthMetric

O HealthMetric nasceu como um projeto prático para aplicar conhecimentos em desenvolvimento web na criação de uma ferramenta útil e funcional. A proposta é oferecer calculadoras de saúde com uma interface limpa, responsiva e fácil de usar.
Mais do que apenas uma aplicação, o projeto representa a evolução técnica, organização de código e preocupação com experiência do usuário durante o desenvolvimento.

Tecnologias Utilizadas

Este projeto foi desenvolvido como parte da evolução dos meus estudos na área de desenvolvimento web, aplicando conceitos de HTML, CSS e JavaScript na construção de uma aplicação funcional, organizada e responsiva.
